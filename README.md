## Overview

Predicts the resale price of used cars in India using **Random Forest Regression**, trained on features like car age, mileage, brand, fuel type, and transmission. Covers the full pipeline — data cleaning, EDA, feature engineering, model comparison, and evaluation.

## Key Findings

- Vehicle age has the strongest negative impact on resale price
- Lower mileage and diesel fuel correlate with higher resale value
- Premium brands depreciate more slowly
